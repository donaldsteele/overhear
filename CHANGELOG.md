# Changelog

## 0.1.1 (2026-11-22)

- `--proto NAME[,NAME...]` captures only the protocols named: `arp`, `dhcp`,
  `nd`, `mdns`, `llmnr`, `nbns`, `ssdp`, `lldp`, `cdp` and `stp`. It can be
  repeated, works in every output mode, live and with `-r`, and combines with
  filter words.
